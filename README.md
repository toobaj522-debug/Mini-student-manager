# Student Project Manager

A beginner-level C++ project that stores and searches student information.

## Features

* Store information for 5 students
* Store student name
* Store student age
* Store attendance status
* Search for a student by name
* Display the student's information
* Shows "Student not found" if there is no match

## Concepts Used

* Arrays
* For loops
* If statements
* Strings
* Boolean variables
* Searching
* User input/output

## How It Works

The program first asks the user to enter information for 5 students.

The user can then enter a student's name to search for their stored information.

The program checks each name in the array and displays the matching student's information.
